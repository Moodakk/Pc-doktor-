# Dental Archive Manager

Офлайн-додаток для Windows, який сканує вибрані папки, групує стоматологічні дані та дозволяє **галочками** вирішити, що залишити, скопіювати, перенести, відкласти в карантин або перемістити до Кошика.

## Що він розпізнає

- КТ / CBCT із DICOM-метаданих;
- стоматологічні рентгени (`DX`, `CR`, `IO`, `PX` тощо), УЗД (`US`) і МРТ (`MR`) як інші DICOM;
- DICOM-документи: Structured Report (`SR`), інкапсульований PDF — у причині видно, що це документ у DICOM-обгортці;
- файли `DICOMDIR` прив'язуються до свого дослідження, а не показуються окремо;
- об'ємні експорти CBCT без DICOM: NIfTI (`.nii`, `.nii.gz`), NRRD, MetaImage (`.mha`/`.mhd`), VTK;
- відео (`.mp4`, `.avi`, `.mov`, `.mkv`, `.webm`, `.mpg`, `.3gp`, `.flv` тощо) — окрема категорія з власною папкою архіву;
- фотографії пацієнтів за структурою папок і назвами;
- STL/OBJ/PLY/3MF та інші 3D-моделі;
- документи й архіви;
- порожні, тимчасові та незавершені файли;
- точні дублікати за SHA-256;
- **реальний тип файлу за вмістом (сигнатурою)**: файли без розширення або з неправильним розширенням розпізнаються за першими байтами (JPEG, PNG, TIFF, PDF, ZIP/DOCX, RAR, 7z, STL, відео тощо), а невідповідність розширення вмісту показується в причині.

DICOM-зрізи одного дослідження показуються одним рядком, а не сотнями окремих файлів. Сканування виконується у кілька потоків: класифікація та пошук дублікатів розпаралелені, а для однакових за розміром файлів спочатку порівнюється короткий префікс і лише збіги хешуються повністю.

## Мова інтерфейсу

Інтерфейс доступний українською та англійською. Мова визначається з налаштувань системи, її можна змінити перемикачем у заголовку — вибір запам'ятовується разом з останніми папками-джерелами та призначенням.

## Логічні зв'язки між файлами

Після сканування програма вибудовує зв'язки, які видно в панелі «Деталі»:

- фото, документи, моделі й архіви, знайдені в папці DICOM-дослідження або поруч із нею, прив'язуються до дослідження та **успадковують пацієнта і дату** — тож в архіві вони потрапляють до папки того самого пацієнта;
- файли з однаковою базовою назвою в одній папці (наприклад, `scan.stl` + `scan.pdf`) зв'язуються як супутні (sidecar);
- нумеровані знімки (`IMG_001.jpg` … `IMG_047.jpg`) розпізнаються як одна серія;
- дублікат та його оригінал посилаються одне на одного.

## Безпека

- програма працює локально й нічого не завантажує в інтернет;
- після сканування **нічого не обирається автоматично**;
- «Застосувати рекомендації» лише заповнює план, який можна змінити;
- копія перевіряється SHA-256 до очищення джерела;
- «Перенести» й «У карантин» відправляють оригінал до системного Кошика лише після успішної перевірки копії;
- пряме очищення вимагає вручну ввести `ВИДАЛИТИ`;
- кожен запуск створює JSON-журнал у `_DentalArchive_Logs` та його CSV-копію для таблиць;
- кнопка **«Перевірити архів»** повторно хешує файли з журналів і показує, чи всі копії на місці та не пошкоджені.

## Звіти

- **Експорт CSV** — таблиця всіх знайдених елементів (відкривається в Excel);
- **Статистика** — підсумки за категоріями та пацієнтами з можливістю зберегти автономний HTML-звіт;
- після виконання плану доступні кнопки відкриття журналу, папки призначення та списку помилок.

> Програма не є резервним копіюванням сама по собі. Для клінічних даних зберігайте щонайменше дві перевірені копії на різних носіях і дотримуйтеся GDPR та внутрішньої політики клініки.

## Найпростіший запуск у Windows

1. Розпакуйте папку програми.
2. Двічі клацніть `START_APP.bat`.
3. Якщо Python відсутній, запускник запропонує встановити Python 3.13 через Windows Package Manager. Можна відмовитися й встановити його вручну з [python.org](https://www.python.org/downloads/windows/) із галочкою **Add python.exe to PATH**.
4. Додайте папки-джерела.
5. Оберіть зовнішній диск або папку призначення.
6. Натисніть **Сканувати**.
7. Перегляньте категорії, поставте галочки та призначте дії.
8. Натисніть **Виконати обраний план**.

Перший запуск встановить три локальні залежності у `.venv`; наступні запуски будуть швидшими.

## Безпечна проба перед реальними даними

1. Двічі клацніть `CREATE_DEMO_DATA.bat`.
2. У програмі додайте створену папку `DEMO_DENTAL_DATA`.
3. Як місце призначення оберіть будь-яку порожню тестову папку.
4. Перевірте категорії та журнал операції.

Демо-набір містить лише синтетичні файли з великим написом `NOT A REAL PATIENT`.

## Збірка одного EXE

На Windows двічі клацніть `BUILD_WINDOWS_EXE.bat`. Готовий файл буде тут:

```text
dist\DentalArchiveManager.exe
```

PyInstaller потрібно запускати на Windows, щоб отримати Windows EXE.

## Логіка дій

| Дія | Що відбувається |
|---|---|
| Залишити | Файл не змінюється |
| Копіювати | Створюється й перевіряється копія, джерело залишається |
| Перенести | Створюється й перевіряється копія, потім джерело йде до Кошика |
| У карантин | Те саме, але копія потрапляє в `_QUARANTINE/дата` |
| До Кошика | Без копії; потрібне окреме текстове підтвердження |

## Тести

```bash
python -m unittest discover -v
```

Тестовий набір створює лише синтетичні DICOM і тимчасові файли; реальні дані пацієнтів не використовуються. Ті самі тести автоматично запускаються в GitHub Actions на Windows та Linux, а тег `v*` збирає готовий Windows EXE у розділі Releases.
